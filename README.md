# 点餐灵感生成器 🍜

基于 Ant Design 6.1.4 的点餐推荐应用，帮助用户在30秒内找到符合口味和预算的新选择。

## ✨ 特性

- 🎯 **智能推荐**: 基于用户偏好（性别、年龄、口味、预算）使用 LLM API 生成个性化推荐
- 🎲 **随机推荐**: 一键随机尝试新菜品
- 📱 **响应式设计**: 完美适配电脑端和手机端
- 💾 **本地存储**: API 配置保存在浏览器本地，无需重复输入
- 🎨 **现代化 UI**: 渐变色背景、卡片式布局、流畅动画

## ⚙️ 配置说明

首次使用前，需要配置 SiliconFlow API：

1. 点击右上角的"设置"按钮
2. 填写以下信息：
   - **API 地址**: `https://api.siliconflow.cn/v1/chat/completions`
   - **API 密钥**: 在 SiliconFlow 控制台获取
   - **模型名称**: `Qwen/Qwen3-8B` 或其他可用模型

## 🎮 使用说明

### 偏好设置

1. **性别**: 选择您的性别
2. **年龄**: 拖动滑块设置年龄（18-80岁）
3. **口味偏好**: 选择辣/清淡/酸甜/随机
4. **预算范围**: 设置价格区间（5-100元）

### 生成推荐

- **生成推荐**: 基于您的偏好调用 AI 生成推荐（需要配置 API）
- **随便试试**: 随机从符合条件的菜品中选择推荐（无需 API）

### 查看推荐

推荐以卡片形式展示，包含：
- 菜品图片
- 菜品名称
- 价格
- 口味标签
- 推荐理由
- 所属餐厅

点击菜品卡片可跳转至商家点餐页面。

## 📝 核心功能

### 1. 偏好选择器
- 性别选择（男/女）
- 年龄滑块（18-80岁）
- 口味选择（辣/清淡/酸甜/随机）
- 预算滑块（5-100元，范围选择）

### 2. 推荐生成
- 调用 SiliconFlow API
- 使用 Qwen/Qwen3-8B 模型
- 根据用户偏好和历史数据生成推荐
- 最多返回5个推荐

### 3. 随机推荐
- 从符合条件的菜品中随机选择
- 最多返回8个推荐
- 无需 API 配置

### 4. 结果展示
- 卡片式布局
- 响应式设计（1-4列自适应）
- 包含图片、名称、价格、标签、推荐理由
- 点击跳转功能

## 🌟 MVP 版本特点

- ✅ 实时读取合作商家菜品数据（模拟）
- ✅ 读取用户最近30天历史订单（模拟）
- ✅ 口味偏好选择器
- ✅ 预算范围滑块
- ✅ "生成推荐"按钮（调用 LLM API）
- ✅ "随便试试"按钮（随机推荐）
- ✅ 推荐结果卡片展示
- ✅ 响应式设计（电脑端和手机端）

## 🚫 MVP 不包含的功能

- 不保存用户个人信息
- 不实现多条件复合筛选
- 不实现长期学习用户偏好
- 不整合支付或下单功能
- 不支持自定义菜品标签

## 📱 响应式断点

- **手机端**: < 768px
- **平板端**: 768px - 1024px
- **电脑端**: > 1024px
